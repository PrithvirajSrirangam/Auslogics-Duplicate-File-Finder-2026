## ❓ FAQ

**Q: Is there any risk of getting banned or detected for using this tool?**  
A: No. This is a legitimate utility for file management. It does not modify system files or interfere with any software. There is zero risk.

**Q: I get an error "Access Denied" when scanning certain folders. What should I do?**  
A: Run the program as Administrator (Windows) or grant Full Disk Access (macOS → System Preferences → Security & Privacy → Privacy → Full Disk Access). Restart the application after changing permissions.

**Q: Can I use this tool on a network drive or external hard drive?**  
A: Yes. Simply select the drive or folder during the scan setup. Network drives may be slower due to latency. We recommend using the "Content" scan mode for external drives for accurate results.

**Q: How do I recover accidentally deleted duplicates?**  
A: If you enabled the "Move to Recycle Bin" option, check your Recycle Bin (Windows) or Trash (macOS). Alternatively, the backup folder (set in settings) contains copies. By default, backups are stored in `./backups` relative to the application directory.
